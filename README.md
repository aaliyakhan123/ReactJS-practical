# React Product Management App

A simple **Product Management Web Application** built using **React, Redux Toolkit, React Router, Bootstrap, Axios, and JSON Server**.
This project allows users to **sign up, log in, and manage products** with full CRUD functionality.

---

## Features

* User Authentication (Login & Signup)
* Protected Routes using PrivateRoute
* Add New Products
* Edit Existing Products
* Delete Products
* Search Products by Title
* Filter Products by Category
* Sort Products by Price (Low → High / High → Low)
* Responsive UI using Bootstrap
* Backend simulation using JSON Server

---

## Technologies Used

* React
* Redux Toolkit
* React Router DOM
* Axios
* Bootstrap
* JSON Server

## Installation

Clone the repository:

```
git clone https://github.com/yourusername/product-management-app.git
```

Move into the project folder:

```
cd product-management-app
```

Install dependencies:

```
npm install
```

---

## Run the Application

Start the React development server:

```
npm run dev
```

---

## Run JSON Server

Start the backend server:

```
json-server --watch db.json --port 3000
```

API endpoints:

```
http://localhost:3000/products
http://localhost:3000/users
```
